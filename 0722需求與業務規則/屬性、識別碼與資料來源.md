
E. 屬性定義表

| 實體                      | 屬性               | 中文名稱     | PK／FK | 型態概念    | 必填 | 規則或允許值                                | 來源                     |
| ------------------------- | ------------------ | ------------ | ------ | ----------- | ---- | ------------------------------------------- | ------------------------ |
| `activity_applications` | `application_id` | 申請編號     | PK     | 字串 / 數字 | 是   | 主鍵唯一性約束[cite: 6]                     | 處理程序 1.0[cite: 3, 6] |
| `activity_applications` | `activity_name`  | 活動名稱     | -      | 字串        | 是   | 必填欄位不得為空[cite: 6]                   | 處理程序 1.0[cite: 3, 6] |
| `activity_applications` | `activity_date`  | 活動日期     | -      | 日期        | 是   | 日期不得為過去時間[cite: 6]                 | 處理程序 1.0[cite: 3, 6] |
| `activity_applications` | `activity_time`  | 活動時間     | -      | 時間區間    | 是   | 結束時間須晚於開始時間[cite: 8]             | 處理程序 1.0[cite: 3, 8] |
| `activity_applications` | `venue_id`       | 場地編號     | FK     | 字串        | 是   | 須對應至有效之場地編號                      | 處理程序 1.0[cite: 3]    |
| `activity_applications` | `status`         | 申請狀態     | -      | 字串        | 是   | 字串（如：待審核、審核通過、退回）[cite: 6] | 處理程序 3.0[cite: 3, 6] |
| `venue_bookings`        | `booking_id`     | 借用紀錄編號 | PK     | 字串 / 數字 | 是   | 主鍵唯一性約束                              | 處理程序 1.0[cite: 3]    |
| `system_users`          | `user_id`        | 使用者帳號   | PK     | 字串        | 是   | 主鍵唯一性約束                              | 管理員維護[cite: 3]      |
