
J. DFD／ERD／原型假資料一致性矩陣

| 資料概念   | DFD 位置                        | ERD 實體／屬性                                                                      | 原型假資料位置                              | 規則或計算                             | 一致／部分／不一致 | 修正或待確認                   |
| ---------- | ------------------------------- | ----------------------------------------------------------------------------------- | ------------------------------------------- | -------------------------------------- | ------------------ | ------------------------------ |
| 活動申請   | 處理程序 1.0, 3.0 / D1 資料儲存 | `activity_applications` (`activity_name`, `activity_date`, `activity_time`) | `activity_form.html` / `mock_data.json` | 必填欄位不得為空，日期不得為過去時間   | 一致               | 名稱與型態前後對應一致         |
| 場地與時段 | 處理程序 2.0 / D2 資料儲存      | `venue_bookings` (`venue_id`, 借用日期, 時段區間)                               | `conflict_check.js` / `mock_data.json`  | 結束時間須晚於開始時間，且不得重複預約 | 一致               | 透過 D2 進行自動化時段衝突檢核 |
| 申請狀態   | 處理程序 3.0, 5.0 / D1 資料儲存 | `activity_applications` (`status`)                                              | `application_status.html`                 | 狀態包含待審核、審核通過、退回         | 一致               | 狀態代碼與顯示介面一致         |
| 審核決策   | 處理程序 4.0, 5.0 / D1 資料儲存 | `activity_applications` 審核相關屬性                                              | `admin_review.html`                       | 審核動作為必填，退回時意見不得為空     | 一致               | 支援批准與退回選項與意見記錄   |
| 系統使用者 | 處理程序 1.0, 4.0 / D3 資料儲存 | `system_users` (`user_id`, 姓名, 角色)                                          | 登入模組 / 模擬帳號清單                     | 依據角色權限區分操作介面               | 一致               | 權限對應關係正確               |
| 場地清單   | 處理程序 1.0, 2.0 / 外部查詢    | `venues` (`venue_id`, 場地名稱)                                                 | `activity_form.html` 場地下拉選單         | 須對應至有效之場地編號                 | 一致               | 下拉選單選項與基本資料表一致   |
| 狀態查詢   | 處理程序 3.0 / D1 資料儲存      | `activity_applications` (`application_id`)                                      | `application_status.html`                 | 依據申請編號或社團代號進行查詢         | 一致               | 查詢請求與回應欄位對應         |
| 衝突比對   | 處理程序 2.0 / D2 資料儲存      | `venue_bookings` 比對邏輯                                                         | `conflict_check.js` 判斷結果              | 比對現有借用紀錄以輸出布林值結果       | 一致               | 規則與資料結構吻合             |
