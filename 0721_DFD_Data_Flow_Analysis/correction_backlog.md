

### H. 第 0 層資料流程圖檢查

| 檢查項目                       | 是／否 | 證據或修正                                                                                                 |
| ------------------------------ | ------ | ---------------------------------------------------------------------------------------------------------- |
| 有 4 至 7 個處理程序           | 是     | 第 0 層處理程序清單中包含從 1.0 至 7.0 共 7 個處理程序，符合 4 至 7 個之規範。                             |
| 至少 2 個資料儲存              | 是     | 包含 D1 活動申請資料表、D2 場地借用紀錄表與 D3 系統使用者權限表，共 3 個資料儲存。                         |
| 處理程序使用動詞加名詞         | 是     | 所有處理程序名稱（如「活動申請管理」、「場地時段衝突檢核」、「後台活動審核處理」等）皆採用動詞加名詞命名。 |
| 資料流與資料儲存使用名詞       | 是     | 所有資料流（如「活動申請請求」、「待審核清單與明細」）與資料儲存名稱皆使用名詞。                           |
| 每個處理程序有合理輸入與輸出   | 是     | 每個處理程序均具備明確且對應的輸入資料與輸出回應。                                                         |
| 每個資料儲存都經由處理程序讀寫 | 是     | D1、D2、D3 皆明確被對應的處理程序進行讀取（R）與寫入（W）操作。                                            |
| 沒有外部實體直接連到資料儲存   | 是     | 外部實體與資料儲存之間無直接連線，所有互動皆透過處理程序轉介。                                             |
| 沒有資料儲存直接連到資料儲存   | 是     | 資料儲存之間無直接連線，符合 DFD 規範。                                                                    |
| 沒有外部實體直接連到外部實體   | 是     | 所有外部實體僅與系統內部之處理程序進行資料交換，實體與實體間無直接連線。                                   |
| 外部資料流與系統環境圖一致     | 是     | 第 0 層的外部資料流（如 EX-01～EX-08）皆與系統環境圖之定義完全對應且保持一致。                             |
